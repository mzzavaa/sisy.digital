# SISY Digital - Women in Tech

Landing page for [sisy.digital](https://sisy.digital) - the SISY hub for women experts in technology.

## What is SISY Digital?

SISY Digital connects and celebrates women shaping the digital world - in AI, cybersecurity, cloud engineering, product management, and software engineering. It features a tech expert directory, conference CFP alerts, the Breaking the Panel campaign, and curated resources by field.

## Tech Stack

- [Hugo](https://gohugo.io) static site generator (v0.142.0 extended)
- Hosted on GitHub Pages with custom domain
- Inter + Playfair Display fonts
- Lucide icons
- Dark mode toggle (respects system preference)

## Local Development

```bash
hugo server -D
hugo --gc --minify
```
